# Agent 实现清单

目标：实现完整 Agent 功能，复刻用户参考的 Qoder 工作方式。保留 AppKit、低内存与低能耗约束。此清单用于追踪完整目标，不把阶段交付当作完成。

对标来源（2026-11-06 核对）：[桌面版功能](https://docs.qoder.com/qoder/overview)、[任务管理](https://docs.qoder.com/qoder/task-management)、[执行监控](https://docs.qoder.com/qoder/task-monitor)、[审批与隔离](https://docs.qoder.com/qoder/approval-and-sandbox)、[扩展](https://docs.qoder.com/qoder/connectors)。用户前面的界面参考作为布局依据；完整 IDE 编辑器是否纳入仍待用户答复，共用 Agent 核心先推进。

## 现有基线

v0.8.2 已有原生聊天、BYOK 模型配置、MiniMax 语音、离线声学唤醒、桌宠互动、闲置屏幕评论。尚无执行任务的工具循环，不具备文件编辑、终端执行或持久任务系统。

## 实施顺序

1. 原生 Agent 数据模型、任务存储、工具循环、文件与终端工具、联网工具和审批。
2. 接入原生任务界面、执行记录与产物；真实模型跑通一项文件任务、审批和停止。
3. 项目与任务完整管理、变更审阅/撤回/Git、记忆与索引、上下文压缩。
4. 浏览器与桌面工具、附件、Skills/MCP/Hooks/插件、自定义 Agent 与协作。
5. 定时任务、其他扩展与远程接入，完成全部能力逐项审计；原目标保持 active，直到实际证据充分。

## 验证约定

优先验证真实业务流程、真实模型和实际落盘结果。只做当前风险需要的最少检查；构建或模拟响应不能替代 Agent 效果验收。现有个人配置、Token、聊天历史和未发送草稿必须保留。测试使用独立临时项目，不把私人文件、截图或凭据写入 Git。

## v0.9.0 阶段证据

真实 `deepseek-flash` 读取临时项目的 `sales.csv`，在逐次确认模式下写入 `result.md`，通过实际 `awk` 输出独立核算总额 **49.00**；输入文件未改动。计划与完成证据由真实工具结果生成，未使用模拟模型响应。模型额外提出的命令被拒绝后能继续。修正证据反馈后，新任务直接完成，只请求写入和命令两项审批，没有再循环询问内部证据格式。

同一生产实现验证了工作区与外部符号链接边界、内核拦截项目外写入、停止清理普通子进程、超时、检查点恢复及用户改动冲突保护。原生界面验证正常/窄窗口、跨任务草稿、设置返回、产物与实际文件一致和真实 unified diff。网页工具实际读取 Qoder 文档，并从公共搜索返回可核对来源；Bing 公共检索对复杂查询可能过宽，站点过滤无命中会报错，不拿无关结果冒充命中。
