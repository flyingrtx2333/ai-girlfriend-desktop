# 接下来：陪你看屏幕

状态：**待实现**。当前版本不会自动截屏、理解视频或主动评论屏幕。Git 基线与文档已建立，后续再做此功能。

## 想要的体验

你在看视频，小鲸闲着摇尾巴。过一会儿，她转头看向屏幕，眼神扫一下，歪头想一想，再轻声评论一两句，随后回到待机。

预期流程：

**待机 → 看看屏幕的动画 → 获取一帧屏幕 → 思考动画 → 短评与口型 → 回到待机。**

「这段配乐和画面好搭呀。」是期望的使用示例，不是当前模型已经识别出的内容。静态截图只能作为一次视觉观察，不能声称听见视频声音或看懂完整剧情。

## 首个版本范围

- 设置中开启或关闭屏幕观察，并选择观察间隔；默认关闭。
- 「闲置」指角色没有正在触摸、拖动、聆听、回复或播放语音；不要求用户停止看视频。交互、锁屏或休眠时暂停观察。
- 观察动画包括转头、视线移动和发梢／尾巴的跟随；思考动画包括歪头、眨眼、轻微重心变化。等待模型时动画继续，收到结果或失败后自然收势。
- 使用配置好的视觉模型；只配置文字模型时不执行观察。首次使用由用户授予 macOS 屏幕录制权限。
- 单次抓取一帧并缩小，发送到已配置的视觉服务；不持续录屏。画面相似时跳过重复点评，一次最多一两句。
- 启用语音回复时继续用 MiniMax，口型随音量变化；否则只显示短气泡。
- 支持暂停与免打扰；控制请求频率和图片大小，优先保证低能耗与成本。

## 完成标准

1. 能看出「观察」「思考」「评论」三个不同阶段，头发、衣摆、尾巴的细动不中断。
2. 真实屏幕场景里，模型评论与当前可见画面相关；不编造看不到的剧情或听不到的声音。
3. 关闭、锁屏、休眠和正在对话时不抓屏，不留下截图文件。
4. 没有新画面、不值得说话或请求失败时安静回到待机，不反复打断。
