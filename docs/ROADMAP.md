# 屏幕陪伴

状态：**v0.8.0 已实现首版**。自动观察默认关闭，需在设置中开启并授予 macOS 屏幕录制权限。

## 想要的体验

你在看视频，小鲸闲着摇尾巴。过一会儿，她转头看向屏幕，眼神扫一下，歪头想一想，再轻声评论一两句，随后回到待机。

当前流程：

**待机 → 看看屏幕的动画 → 获取一帧屏幕 → 思考动画 → 短评与口型 → 回到待机。**

每次只看一帧当前应用窗口，不采集声音，不能声称听见视频配乐或看懂完整剧情。评论以可见画面为依据；没有值得说的内容时安静回到待机。

## 首个版本范围

- 设置中开启或关闭屏幕观察，并选择观察间隔；默认关闭。
- 「闲置」指角色没有正在触摸、拖动、聆听、回复或播放语音，距上次角色交互至少 20 秒；不要求用户停止看视频。交互、锁屏或休眠时暂停观察。
- 观察动画包括转头、视线移动和发梢／尾巴的跟随；思考动画包括歪头、眨眼、轻微重心变化。等待模型时动画继续，收到结果或失败后自然收势。
- 使用配置好的视觉模型；只配置文字模型时不执行观察。首次使用由用户授予 macOS 屏幕录制权限。
- ScreenCaptureKit 单次抓取当前应用的可见主窗口，最长边 1280 像素，内存压缩为 JPEG 后发送到已配置的视觉服务；不持续录屏、不保存截图。前台应用变化时取消未完成的观察。
- 画面相似时在本地跳过；模型知道最近三条评论，收到 `[安静]` 时不发言。提示模型跳过私人聊天、密码、验证码等内容。
- 启用语音回复时继续用 MiniMax，口型沿实际音频时间线变化；否则只显示短气泡。主动评论不打开续聊麦克风。
- 支持暂停与免打扰；控制请求频率和图片大小，优先保证低能耗与成本。

## 完成标准

1. 能看出「观察」「思考」「评论」三个不同阶段，头发、衣摆、尾巴的细动不中断。
2. 真实屏幕场景里，模型评论与当前可见画面相关；不编造看不到的剧情或听不到的声音。
3. 关闭、锁屏、休眠和正在对话时不抓屏，不留下截图文件。
4. 没有新画面、不值得说话或请求失败时安静回到待机，不反复打断。

## 后续方向

- 按应用单独设置观察偏好。
- 在保持低频与低成本的前提下评估多帧观察；当前仍只理解单帧。
