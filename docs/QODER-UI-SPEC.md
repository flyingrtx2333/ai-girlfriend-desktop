# 小鲸界面规范：Qoder Agent 对标

更新日期：2026-11-16。参考固定为本机 Qoder 0.5.2 的实际窗口；保留小鲸品牌、用户选定的 A 任务工作台、AppKit 及已实现的主题。对标范围是桌面 Agent，完整 IDE 编辑器另行规划。

本文件规定后续页面的共同标准。逐页实现、窗口验收与日常发布状态以 [Qoder TODO](QODER-PARITY-TODO.md) 为准。

## 页面承载

| 场景 | 承载与导航 | 参考与现有组件 |
| --- | --- | --- |
| 主窗口 | 左侧任务与工作区，右侧当前任务或主内容；需要我、自动化、知识中心使用连续主页面 | Qoder 主窗口参考；`ControlWindow`、`AgentWorkbenchTheme` |
| 设置 | 左侧固定返回与搜索，分类独立滚动；右侧标题、居中内容列、当前范围 | Qoder 记忆页；`AgentSettingsPageHost` |
| 搜索 | 展示设置名称、所属分类和打开动作；侧栏保留匹配分类，打开后恢复完整导航 | Qoder 实机设置搜索；`settingsSearchMatches` 与 `openSettingsSearchResult` |
| 管理列表 | 按实际范围或来源分组；行内包含名称、必要状态和操作，使用一致的选中与悬停颜色 | Qoder 智能体列表、MCP 工具目录；`AgentSettingsTableRow`、分组卡片 |
| 详情及长编辑 | 在原页面逐级进入，保留返回入口、范围、草稿和滚动；按字段用途分卡 | Qoder 智能体配置；`AgentSettingsStyle.section`、`form` |
| 任务产物 | 在所属任务的标签页或右侧工作区内读取、编辑；独立窗口有明确入口与返回 | 已确认的任务工作台方案；`AgentTaskWorkspace` |
| 短表单与确认 | 名称、图标、颜色等短编辑使用统一轻量表单；确认显示对象、影响与明确按钮 | Qoder 重命名及工作区编辑；`AgentNameEditor`、`AgentWorkspaceEditor`、`AgentConfirmation` |
| 系统流程 | 文件选择和系统授权沿用系统面板，返回原页面并反馈取消或错误 | AppKit 系统面板 |

长配置通过页内详情完成，避免多层管理弹窗。管理页的保存只作用于当前对象和范围。搜索结果不提供与当前入口无关的保存动作。

## 视觉基础

颜色使用语义角色，由 `AgentWorkbenchTheme`、`AgentThemeContext` 与 `AgentThemeStyles` 解析。下面是当前基础明暗值；主题绑定可以覆盖相应角色。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `sidebar` | `#edeff3` | `#1c1e22` | 导航背景 |
| `surface` | `#fefefe` | `#242629` | 内容表面和卡片 |
| `settings` | `#fcfcfc` | `#242629` | 设置内容背景 |
| `line` | `#d6dbe0` | `#3a3d42` | 分隔线和边界 |
| `selection` | `#d1e4e2` | `#28453f` | 选中的对象 |
| `subtle` | `#f2f3f5` | `#303338` | 次级表面 |
| `secondaryText` | `#59616b` | `#b6bbc4` | 元数据和次要状态 |
| `accent` 基础回退 | `#057561` | `#6bd4b6` | 主操作和启用状态 |

导航选中和悬停使用独立角色。新增控件取语义颜色，跟随明暗和主题变化；文字、代码、差异和禁用状态保持可读。

| 元素 | 规范 |
| --- | --- |
| 页标题 | 20 pt、半粗，位于右侧内容列 |
| 分组标题 | 12 pt、中等字重、次要文字色 |
| 设置标签与控件 | 13 pt，标签与对应控件对齐 |
| 次要状态 | 11–12 pt；错误可换行，完整内容可读取 |
| 对话与文档 | 跟随用户字号和字体风格；代码保持等宽 |
| 卡片 | 12 pt 圆角、1 pt 边界、横向 16 pt／纵向 10 pt 内边距；分组标题缩进 16 pt，与行标签对齐 |
| 设置行 | 内容最小 32 pt；标准单行连同留白为 52–53 pt，按内容扩展；标签与控件间距 12 pt |
| 分组间距 | 24 pt；卡片内部按内容使用 8、12、16 pt 间距 |
| 工具栏图标 | 常用图标 16 pt、按钮区域 28×28 pt；必须有可访问名称 |
| 设置侧栏 | 常规 252 pt，对齐 Qoder 0.5.2 实机；窄窗口 180 pt；搜索与分类滚动分开 |
| 核对尺寸 | Qoder 同尺寸视觉窗口 1320×800；原生布局内容 1200×774、800×550，最小窗口 780×540；内容通过滚动保持可达 |

布局优先表达用途：清晰分组、间距、标签和熟悉的控件。省略重复副标题、卡片下的说明段和装饰文案；保留权限、错误、费用或不可恢复动作所需的信息。

## 控件、状态与内容

- 输入框、选择框、分段控件和开关复用公共设置组件。开关直接保存时显示实际结果；失败恢复原值并提供可用的重试入口。
- 主操作和普通操作有明确层级；删除、覆盖及执行授权显示实际对象和影响。确认名单较长时允许滚动，保留完整名单。
- 普通确认复用 `AgentConfirmation`，当前标准宽度 440 pt；长详情在框内滚动。业务入口不直接创建原始 `NSAlert`。
- 状态文字反映实际数据与操作结果。没有内容时展示空态及可执行入口；加载时显示正在执行的动作；错误保留用户输入并提供恢复路径。
- 列表和卡片按实际来源标明用户、项目、本机或插件范围；数量、连接状态和保存反馈来自真实存储或会话。
- 编辑正文可选择、复制、撤销和滚动；代码、JSON、Markdown 与普通设置字段使用适合其内容的字体和布局。说明、正文与长路径不能撑大窗口。
- 有效指令、来源预览等只读内容保持可读、可复制；权限操作沿用原授权流程。

## 导航和键盘

1. 打开具体设置后显示目标控件或子页，焦点进入相应输入或操作。
2. 进入编辑器时焦点进入正文或首个编辑字段；返回后定位到原对象或入口。
3. 未保存时，返回、切换范围、搜索跳转、切换任务和关闭均使用同一离开检查。继续编辑恢复原草稿、输入焦点和光标位置。
4. 保存作用于当前对象；保存失败保留输入、原内容、权限和并发修改保护。快捷键与可见按钮执行相同操作。
5. 设置、主内容和任务工作区之间往返时保留当前任务、未发送输入、附件及所属关系。
6. 内层能滚动时使用内层；到达当前方向边界时衔接外层。连续触控板手势和惯性单独实机核对。
7. 动效尊重系统“减弱动态效果”；验收后恢复临时改变的系统偏好。

## 验收与状态记录

每个新增或修改的页面按其实际入口检查：浅深色、正常／窄窗口、键盘、范围切换、保存反馈、未保存保护和同版重开；涉及写入时核对实际文件和原任务。只读、冲突、权限和取消覆盖相关分支。

原生检查、实际窗口、模型结果和日常发布分别记录。独立验收应用不等于日常应用已更新；模型效果使用对应任务授权和独立记录。规范已建立不等于全部页面已经套用，统一控件和逐页验收继续保留在 TODO。
