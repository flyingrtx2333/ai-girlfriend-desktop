# 小鲸界面规范：Qoder Agent 对标

更新日期：2026-11-21。参考固定为本机 Qoder 0.5.2 的实际窗口；保留小鲸品牌、用户选定的 A 任务工作台、AppKit 及已实现的主题。对标范围是桌面 Agent，完整 IDE 编辑器不纳入当前范围。

本文件规定后续页面的共同标准。逐页实现、窗口验收与日常发布状态以 [Qoder TODO](QODER-PARITY-TODO.md) 为准。

| 管理列表 | 按实际范围或来源分组；行内包含名称、必要状态和操作，使用一致的选中与悬停颜色 | Qoder 智能体列表、MCP 工具目录；`AgentSettingsTableRow`、分组卡片 |

| 工作树创建与管理 | 沿任务审阅进入；创建先预览，管理按宽度采用左右或上下布局，回收／恢复在详情中审阅 | `AgentWorktreeCreationWindow`、`AgentWorktreeWindow` |

| Git 依赖漏洞报告 | 沿任务审阅进入；来源／范围、结果与可滚动详情分区，保留原报告、公告与返回 | `AgentDependencyWindow`、共享选择器及按钮 |

长配置通过页内详情完成，避免多层管理弹窗。管理页的保存只作用于当前对象和范围。搜索结果不提供与当前入口无关的保存动作。

插件历史在插件详情下打开，标题包含插件名和当前版本。旧版本按时间倒序列出，选择一项进入变更审阅，取消返回原行。空目录保留创建或导入入口，以及适用的筛选和空态提示。目录有记录时显示数量。

连接器和 Hooks 的 JSON 格式错误在正文上方显示修正提示，保留当前输入。Hooks 的保存放在固定操作区。禁用动作使用中性描边和次要文字，审批状态随浅色和深色使用各自的可读强调色。

### 任务工作台

侧栏把当前任务滚入视野，列表与顶栏共用状态图标和颜色。矮窗的侧栏将「更多」和「设置」并在底部一行。顶栏保留任务名、状态、项目、浏览器、终端和监控入口，过长的任务名可悬停查看全文。顶栏可用空间不足时，电脑操作和 Git 移入「任务操作」，沿用原启用状态。输入区可用宽度不足时，将执行位置、分支、模式和审批放在第一行，模型、上下文、语音和发送放在第二行。

任务模型在输入区按钮上方展开，沿用当前主题并保留窗边距。搜索优先选中匹配的模型，也可直接输入模型 ID。「跟随默认」可在完整列表中选择。上下键移动、回车应用，取消后回到原输入区。刷新失败保留搜索及选中项，保存失败保留所选模型供重试。切换任务时关闭选择器。

普通窗口让固定监控与对话并排。780×540 窗口打开固定监控时，监控占满右侧内容区，顶栏与任务列表仍可操作。关闭后恢复原任务的草稿和输入焦点。

任务对话内的审批按内容收缩。终端命令按原行预览，控制和格式字符采用可见转义，联网状态与超时在固定操作行展示。长命令、浏览器目标、连接器说明和参数在正文内滚动，审批按钮与输入区保持可达。补充问询显示待回答的正文及「不回答」。失败提示与「继续」同行，完整错误可选中或悬停查看。

底部终端打开时，对话和输入区收紧纵向留白。审批标题、预览、网络和超时信息及决定按钮保留可读空间。打开当前任务查找时，分隔线给命中原文留出阅读空间，终端仍可操作。草稿附件在同屏时为单行滚动，收起终端后恢复常规高度及输入焦点。

终端默认跟随应用外观。「终端外观」同时提供固定浅色与深色，并标出当前选项。切换时所有已打开的分屏立即换色，保留命令输出和运行中的 Shell。重开恢复布局与外观偏好，分屏按需启动。旧记录升级后沿用保存的配色。

### 设置侧栏

按个人／陪伴／集成／编码／其他组织同一批 22 类设置，保留原路由和索引；陪伴分组是小鲸功能差异。Agent 普通侧栏 252 pt，窄窗按既有响应布局为 180 pt。返回与搜索固定在顶部，分类单独滚动：返回和搜索均为 30 pt，中间 14 pt，分类距搜索 12 pt。分类行 30 pt、间隔 2 pt，分组标题 22 pt、组间 14 pt；导航左 8 pt、右 16 pt。

图标使用统一 16 pt 槽与 14 pt 常规 SF Symbols，正文 13 pt、选中中等字重；6 pt 圆角中性选中底色，非选中使用次要文字。鼠标点击不画键盘焦点框，键盘操作显示 1.5 pt 强调色轮廓。搜索沿用原生搜索／取消语义，30 pt 高、6 pt 圆角及必要焦点边框。

从筛选分类、搜索结果或外部入口进入后，恢复完整分类并把所选项滚入视野；清空查询恢复当前项。未保存跳转取消后保持原草稿与编辑器，恢复唯一选中项和可见位置。实窗验证 Space 激活；macOS 默认 Tab 是否遍历全部按钮及物理悬停不扩大为已完成。

### 内容列与操作

设置标题与当前范围同排，范围采用 12 pt 次要文字并靠右；基础设置和搜索的标题后间距为 30 pt，管理页为 16 pt。只有返回或多页签存在时保留管理导航行，单目录不为范围另占一行；搜索和基础设置隐藏先前的管理范围。多来源选择复用原弹出控件及共享单箭头框，保持原目录与切换保护。

目录详情和内层表单沿用完整内容列，不重复叠加横向边距；内层滚动与底部空间保留。分组标题距卡片 16 pt，卡片内边距和字段层级按既有规则处理。规则按来源列出，通过行尾入口或回车进入全宽正文。返回保留范围、筛选和列表位置，未保存时先处理当前输入。长表单随内容滚动，正文独立滚动并保留选区。

显式保存、应用、模型检测、屏幕操作及宠物复位等动作复用现有 28 pt 高、6 pt 圆角按钮，主要动作使用主题强调色；保持原目标、快捷键、忙碌与禁用行为。普通设置和 Hooks 的 28 pt 图标容器使用强调色 8% 底板，Hooks 的内容卡片与分隔沿用设置语义色。导入来源和 Hooks 范围使用共享单箭头选择器，禁用时箭头随原控件同步变淡。

### 连接器、Hooks 与插件详情

MCP 表单由各字段分组卡片直接承载。JSON 编辑器单独使用一个主题卡片、12 pt 圆角及 1 pt 边框。MCP 与 Hooks JSON 沿完整内容列排布，详情顶部 8 pt、底部 12 pt，保留原文、内层滚动及失败输入。主要操作与更多菜单入口均为 28 pt 高，各操作保持原目标、快捷键与禁用状态。

JSON 语法错误有可靠位置时，在编辑区上方显示行列号和「定位错误」。定位滚动到原稿的对应位置并聚焦光标，修改后清除旧提示。字段、权限及文件变化错误继续显示实际原因。

Hooks 事件行 64 pt，处理器行 48 pt，展开项使用主题选中色。处理器在所属事件内展开详情区，顶部放启用、来源及适用的配置操作，紧接实际错误、完整匹配规则与命令预览。展开时尽量让所选名称、操作和命令开头同屏，预览随内容收紧，超出 144 pt 内滚动，参数可选取。目录为空时显示共用空态。上方范围选择用于编辑和导入，无工作区时「当前项目」禁用。

连接与断开共用一个位置，保存固定靠右，资料与提示词及移除归入更多菜单。配置／工具和表单／JSON 同排，工具页隐藏配置方式。插件的启用状态和组件操作保持在详情上方，启用设置、来源、更新、历史与移除集中在更多菜单。详情底部只显示实际状态和错误，目录总数留在列表。

插件详情的嵌入组件表按实际末行计算高度，首选高度最多 120 pt、最低 44 pt，允许布局收紧并保留内层滚动；README 阅读区最低 80 pt。少量组件不保留固定空高，多组件可到达最后一行。必须在实际 780×540 最小窗口中核对表格、README 和底部操作，不能靠窗口被动增高满足约束；独立承载保留其原布局。

安装、更新、恢复和项目启用共用插件审阅页。设置页首显示动作、插件名、范围和版本，确认与取消固定在右上。文件变更列表可按路径筛选并纵向滚动。所在路径与「差异／全文」切换位于阅读列上方，差异显示行号和增删高亮，全文保留两版内容。

### 智能体与团队详情

目录保留源文件夹选择。进入详情后，页首显示实际对象名称和用户、项目或跨项目范围，右上固定「新建任务」和「保存」。名称与职责使用横向字段，智能体的工作指令紧接基本信息，团队成员区显示负责人和已选成员的名称及来源。字段校验失败时保留当前输入，保存成功后更新页首名称。独立窗口使用页内操作。

### 目录列表

智能体、团队、插件、Skills 和指令共用 64 pt 正文行：13 pt 中等字重名称、12 pt 次要信息、11 pt 必要状态。智能体／团队逐项卡片；插件按实际用户／项目范围，Skills／指令按实际来源连续分组，来源标题 30 pt、组间 12 pt、卡片圆角 10 pt。组内使用轻分隔及语义选中／悬停背景，不逐行叠加边框。来源按原目录首次出现的次序排列，组内保留原顺序、对象 ID 及首次选中项；标题不计入对象数量，不重排持久配置。

28 pt 创建／导入动作位于主窗口右上（距内容面板顶 6 pt、右 12 pt），与范围／搜索独立；主操作靠右，保留原页内创建和返回行为。Skills／指令搜索框至少 140 pt，旧空白占位不带入工具栏。数量只出现一处，底部保留实际反馈和错误。目录根页使用本页按钮，详情和短表单使用各自操作，返回时恢复目录动作及其可用状态。独立承载保留页内工具栏。

初始空态与搜索无结果采用 154 pt 边框内容区、64 pt 原生线框插图及 16 pt 必要状态文字；由页面层承载，与完整内容列对齐，不交给滚动视图内部排布。过滤、清空、取消创建和缩放后核对完整提示、真实数量、原列表及选择。`740a2fa` 的搜索宽度／裁切修复保留，分组与空态已随 `3a79a5e` 安装；顶栏、空态比例和森林层次的本批代表性流程已随 `bbb4965` 安装，不能据此关闭七项整体视觉标准。

森林设置使用独立语义卡片色：浅色侧栏／页面／卡片为 `#F0F2F1`／`#FAFAFA`／`#FFFFFF`，深色为 `#242623`／`#1E231F`／`#191B1A`；其余三个风格的调色板数值保持。强调色保留既有可读文字对比度，未宣称与 Qoder 按钮完全一致。新建表单沿用页面底色，范围菜单关闭自动启用，保留无工作区的项目禁用状态。

### 设置短表单

Skill／指令创建与 MCP 工具规则沿设置右侧进入，字段按用途分组；名称和工具名使用描边输入框与 14 pt 标签，选择器复用 28 pt 单箭头框，取消及主题主操作复用 28 pt 共用按钮并位于窗口右上。独立承载保留紧随错误状态的页内操作，不把按钮推到空白页底部。输入焦点、原选择、错误与 ⌘S 保持；无工作区的项目范围禁用。手动短表单的代表性流程已随 `3e4c9c1` 安装。

MCP 工具权限页首显示当前智能体。重开时恢复工具名、选区、权限、连接器和校验提示。原连接器变更或不可用时保留填写并禁用应用，明确重新选择后可继续。「应用」回到原智能体草稿，「保存」写入该智能体。

Skill 新建菜单提供「通过小鲸创建」与「手动创建」，原生菜单右缘对齐创建按钮，正常与窄窗口内完整显示。任务式创建开启独立计划会话，确认方案后逐文件暂存草稿，再沿设置右侧内容审核；默认用户范围，无工作区禁用项目范围，多来源只能选择原目录。保留来源任务、旧建议改进、手动创建及导入。`e7437e4` 的界面／本地流程已交付；真实模型闭环与全部视觉标准继续开放，见 [本批台账](P0-UI-ACCEPTANCE.md#2026-11-18-skill-任务式创建交付)。

### 数据导入

页内先选择本机来源，检测结果在同一列表按类别显示。复选框切换整类，行尾箭头进入该类的目录、目标和逐条预览。类别与明细均用原生混合状态表示部分勾选，返回后焦点回到原类别。来源不可用和检测错误的详细原因在对应类别读回，导入按钮显示实际选择数。

一次批次可包含同一来源的多个类别。每类分别绑定原目录和目标。暂停或重开后在概览查看整体进度，沿各类别打开单条结果。来源的新记录由下一次检测纳入，已写入结果继续保留。

普通单行字段统一主题卡片填充、6 pt 圆角、1 pt 中性边框及 1.5 pt 焦点；13 pt 文字继续由 AppKit 绘制和编辑，保留原生文字位置。`AgentDialogTextField` 覆盖智能体、团队、MCP 普通字段及模型／语音接口、音色和唤醒词；`AgentSecureTextField` 覆盖模型／语音安全值、MCP Bearer、环境变量与请求头值，保持 `NSSecureTextField` 及原生安全编辑器。模型／预算使用 `AgentComboBox`，保留可编辑文字、原生列表、键盘选择与目标动作；原生完整绘制后再绘制主题表面，避免列表宽度被缩窄。共用外观处理不改变凭据存储、权限或保存逻辑。该输入家族随 `434940e` 交付，同包检查与实窗边界见 [本批台账](P0-UI-ACCEPTANCE.md#2026-11-18-安全输入与模型下拉交付)。

模型字段可直接填写 ID，也可在设置右侧的服务卡片内展开模型列表。列表按名称或 ID 搜索，长 ID 在行内中间省略，悬停查看全文。方向键进入列表，回车或「使用模型」回填草稿。「读取列表」与「检测」各自显示结果。切换接口或编辑 Token 时清除旧目录，手填 ID 保留。

窗口内短卡片继续使用独立字段编辑器，撤销／重做菜单和 ⌘Z／⇧⌘Z 只作用于该卡片，关闭后保留原任务草稿。更多输入变体及编辑／错误／禁用组合继续逐项验收。

### 需要我列表与详情

标题与待关注／历史页签同排，刷新和设置在右侧；类型、来源与搜索组成第二行。历史增加时间与发起者，内容宽度不足 700 pt 时换到下一行，搜索保留至少 140 pt。选择器统一 28 pt 高及单箭头，保持各列表的独立筛选条件。

## 保存反馈与草稿

保存失败显示简短的原因和下一步操作，使用共享语义错误色；主提示不重复完整内部路径。只读、权限不足、空间不足、来源失联和内容已变化分别给出相应操作，保留原始错误诊断供工具提示或日志查看。原因取自明确错误类型及系统错误码，不按错误字符串猜测；未知文件错误保持保守重试提示，已有输入校验与部分成功信息保留原意。

状态随正常赋值恢复次要文字色及工具提示，空状态不占文字内容。错误可换行，压缩时保留完整文字高度；规则与插件错误单独占用内容宽度，底部动作另起一行，来源标签可以省略中段但保留完整路径提示。失败保持正文、字段及所选范围，返回时仍执行未保存保护；恢复条件后使用原按钮或 ⌘S 重试，成功清除旧错误。

规则保存必须尊重文件写入位。只读失败后的重试只在来源、归属及原内容一致时刷新元信息，不能跳过外部修改和原版本保护，也不能把新读到的外部内容直接当作用户同意覆盖。其余配置继续沿原保存服务与权限校验执行。

## Git 主审阅

来源选择器为 28 pt 单箭头入口；文件选择器使用同高描边框，填满文件行可用宽度，右侧保留列表开关。修订字段为 132×28 pt；统一／并排和换行同为 28 pt，保持真实原生菜单及键盘行为。文件行 32 pt、13 pt 字，长路径行内省略但保留完整目标。

暂存、取消暂存、恢复及撤销使用 28 pt 共享动作；恢复使用危险语义。提交说明为 32 pt 描边字段，主提交强调、提交并推送次要；忙碌时禁用相关控件，文字与箭头同步变淡。刷新、来源切换、返回及切换任务前保留正在编辑的提交草稿，提交读取实际编辑器内容。

## Git 推送与工作树操作

推送的远端、地址和提交使用 28 pt 共享描边选择器；分支及远端名称／地址为 32 pt 字段，动作 28 pt。单行字段不折行，长输入横向滚动且保留完整值；保存、准备推送及工作树预览先确认当前真实编辑内容。目标错误保留输入，禁用发送；确认显示实际目标和提交，核对结果不重新推送。差异至少保留 80 pt，可纵向滚动，底部状态按内容换行。

推送提交选择器与 28 pt 统一／并排／换行控件位于同一行；横向分配填满可用宽度，选择器占余宽，阅读控件固定右侧，不随提交标题长短移动。整体变更保留原始统计与补丁；单提交保留真实哈希、作者、日期、标题及对应统计、补丁。整体或单提交被截取时保留对应提示，切回整体仍显示整体提示。目标变化清除旧补丁与行号，失败保留输入并禁用推送。普通推送结果隐藏差异模式、不显示行号，以可选、可换行的普通输出呈现，核对结果不重新发送。

「设置 → Git」的「允许强制推送」默认关闭，切换后立即保存。开启后，手动推送页面在目标无法快进时列出待推送及将从目标分支移出的提交，两组均可打开单提交差异。确认框显示远端地址、源与目标分支、两端提交及移出数量，回车默认取消。发送时核对开关、原仓库与审阅的远端提交。远端发生变化后须重新检查，推送仍受远端的分支策略约束。智能体推送工具沿用快进规则。

新建工作树使用同高起点选择器、分支字段和预览／创建动作。起点菜单区分本地与远程分支，同名分支按各自的 Git 引用选择。780×540 下来源列表纵向滚动，差异预览保留至少 120 pt，预览和创建按钮固定在底部。预览显示实际起点提交与带入范围，来源或起点变化后须重新预览。创建保留原任务草稿和源目录暂存状态，带入工作修改保持未暂存，忽略文件不带入。

「设置 → 工作树」提供「创建前获取上游更新」，默认关闭。开启后在手动预览阶段获取各待创建源的上游，展示获取结果和实际起点。所选本地分支能快进时采用新上游，分叉或上游落后时展示本地起点。创建沿用已审阅的提交，跟踪分支、远端设置或任务范围变化时须重新预览。

上游认证失败时，创建页显示对应项目和远端分支，提示更新 Git 凭据或检查 SSH 密钥。远端拒绝读取时提示检查仓库权限。错误保留原表单供重新预览，创建须等新预览成功后才可继续。

移交继续使用任务 Git 页内审阅。列出来源与本地检出的路径、分支和提交，按提交、已暂存、未暂存切换差异。多源任务逐个审阅，确认按钮标明项目数。本地须干净，冲突或来源变化时保留在审阅页。完成后打开关联的本地任务，保留原工作树与任务历史。

管理列表行高 56 pt，名称 13 pt、路径 11.5 pt；普通窗口左右分栏，窄窗上下排列。完整详情可选择、换行及滚动，底部操作固定可达；回收使用危险语义、恢复使用主要动作。外部工作树在管理页可手动备份回收，主工作树、当前工作树、锁定和关联任务仍在执行的条目显示相应禁用状态。回收审阅列出原目录、分支、备份项数和关联任务，回收／恢复均可取消。备份保留忽略文件、权限和完整暂存状态。自动回收空记录按实际内容收紧为 56 pt，有真实记录或错误时为 150 pt；空态不套用长记录的高度断言。

自动回收在「设置 → 工作树」右侧设置范围、回收条件及保留值。按闲置时间显示期限，按数量显示每项目的上限。项目超额时，按关联任务最近活动及已记录的文件活动优先回收较旧且符合条件的工作树。启用或修改已启用的策略时，在原窗口确认范围与完整备份，默认选中「取消」。跨启动恢复未应用的设置、项目与阅读位置，保存时核对原策略版本。

原目录缺失的登记在同一管理页提供「清理登记…」。审阅显示原路径、分支和备份范围，确认只移走选中的 Git 登记。回收记录显示「Git 登记」，恢复操作为「恢复登记」。登记还原时核对分支与同名路径，已接回的目录须指向同一 Git 登记。

目录已移动时，选中原登记并点击「重新关联…」可选择新目录。确认在原页面进行，显示新旧路径、分支及关联任务。确认后选中新位置，关联任务可从同页打开。取消返回原登记。

当前覆盖及失败历史见 [P0 台账](P0-UI-ACCEPTANCE.md)；复杂详情、差异更多业务状态、主工作台和整页观感仍归 P0-09 跟踪。

## 共享差异阅读器

统一视图保留真实补丁全文、原 UTF-16 选区及复制行为，不通过改写正文插入行号。左侧旧／新行号使用 11 pt 等宽数字，宽度按最大位数计算；编号只出现在实际逻辑行首个可见片段，换行续片不重复。新增、删除和区块使用共享主题的语义背景，原始加减号与区块文本保留；状态与空提示不显示行号。

行号作为与正文滚动视图并列的独立视图，实际占用布局宽度。正文换行宽度取扣除行号后的真实可见区域，不能使用原生标尺负原点下包含行号的 contentSize。横移正文时行号固定，纵向滚动按真实 TextKit 行片段重绘；正文背景、行号和边界绘制均显式裁剪在自己的四边内。

并排标题高 28 pt、12 pt 中等字重；两侧使用相同语义表面，行号列按最大位数拓宽，文本布局和行高测量使用同一实际列宽。单边纵向滚动同步另一边；缺失侧保持占位行高，长中文、表情与无行尾换行的原始内容保留。共享阅读器当前用于任务 Git 审阅、推送整体／单提交、工作树预览和既有知识差异流程，不另开窗口。

本轮原生与实窗覆盖、失败历史见 [P0 台账](P0-UI-ACCEPTANCE.md)。本机 Qoder 0.5.2 原浅色已恢复；未取得其同内容差异页新实图，不以当前代表性阅读流程替代完整视觉对照。

## 控件、状态与内容

- 输入框、选择框、分段控件和开关复用公共设置组件。开关直接保存时显示实际结果；失败恢复原值并提供可用的重试入口。
- 主按钮使用主题强调色与对应文字色；在实际明暗窗口中，文字与背景对比度至少 4.5:1。
- 导入、归档与管理表格共用语义选中行，保留名称和次要状态的可读性。权限状态与对应动作作为同一组对齐至行尾。
- 主操作和普通操作有明确层级；删除、覆盖及执行授权显示实际对象和影响。确认名单较长时允许滚动，保留完整名单。
- 普通确认复用 `AgentConfirmation`，当前标准宽度 440 pt；长详情在框内滚动。业务入口不直接创建原始 `NSAlert`。
- 状态文字反映实际数据与操作结果。没有内容时展示空态及可执行入口；加载时显示正在执行的动作；错误保留用户输入并提供恢复路径。
- 列表和卡片按实际来源标明用户、项目、本机或插件范围；数量、连接状态和保存反馈来自真实存储或会话。
- 编辑正文可选择、复制、撤销和滚动；代码、JSON、Markdown 与普通设置字段使用适合其内容的字体和布局。说明、正文与长路径不能撑大窗口。
- 有效指令、来源预览等只读内容保持可读、可复制；权限操作沿用原授权流程。

## 导航和键盘

1. 打开具体设置后显示目标控件或子页，焦点进入相应输入或操作。
2. 进入编辑器时焦点进入正文或首个编辑字段；返回后定位到原对象或入口。
3. 未保存时，返回、切换范围、搜索跳转、切换任务和关闭均使用同一离开检查。继续编辑恢复原草稿、输入焦点和光标位置。
4. 保存作用于当前对象；保存失败保留输入、原内容、权限和并发修改保护。快捷键与可见按钮执行相同操作。
5. 设置、主内容和任务工作区之间往返时保留当前任务、未发送输入、附件及所属关系。
6. 内层能滚动时使用内层；到达当前方向边界时衔接外层。连续触控板手势和惯性单独实机核对。
7. 动效尊重系统“减弱动态效果”；验收后恢复临时改变的系统偏好。

## 验收与状态记录

每个新增或修改的页面按其实际入口检查：浅深色、正常／窄窗口、键盘、范围切换、保存反馈、未保存保护和同版重开；涉及写入时核对实际文件和原任务。只读、冲突、权限和取消覆盖相关分支。

布局检查按实际内容边界判断：原生只读标签使用排版边界，输入、图标／颜色及动作控件仍检查完整可见区域。

原生检查、实际窗口、模型结果和日常发布分别记录。独立验收应用不等于日常应用已更新；模型效果使用对应任务授权和独立记录。规范已建立不等于全部页面已经套用，统一控件和逐页验收继续保留在 TODO。
